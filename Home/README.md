# Gate 区块链生态系统

Gate 打造了由 GateChain（L1）与 Gate Layer（L2）协同的区块链体系：在保证安全与最终性的前提下，兼顾高性能与低成本，为各类 Web3 应用提供稳定的基础设施。

---

### GateChain

面向资产安全与高可靠性的主链网络，是生态的结算与数据可用性层。

- 兼容 EVM，支持智能合约与丰富生态
- GateMint 共识，提供稳定、快速、即时最终性
- 原生支持 Blob（EIP-4844），降低 L2 数据成本
- 由 GT 质押与治理保障网络安全

[进入 GateChain 文档 »](../GateChain/status/README.md)

---

### Gate Layer

基于 Optimism OP Stack 的 Layer 2 扩容网络，完全兼容以太坊工具链，服务于高吞吐、低费用的应用场景。

- 5,700+ TPS、约 1s 出块，低交易费用
- L2 执行费（EIP-1559）+ L1 数据费（Blob）组合
- 原生集成 LayerZero 与生态跨链能力
- 适配 DeFi、游戏、社交、NFT 等多种类型 DApp
