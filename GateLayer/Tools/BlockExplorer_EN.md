# Block Explorer

Gate Layer uses GateScan, a customized fork of Blockscout, as its official block explorer. It allows you to explore and search the Gate Layer network for blocks, transactions, addresses, and other on-chain activities.

## Networks

You can access GateScan for each network through the following links:

| Network | URL | Status |
| :--- | :--- | :--- |
| Gate Layer Mainnet | `TBD` | Not Launched |
| Gate Layer Testnet | [https://gatescan.org/gatelayer-testnet](https://gatescan.org/gatelayer-testnet) | Live |
