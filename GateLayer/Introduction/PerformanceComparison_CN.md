# 性能对比

与其他 Layer 2 解决方案（如 Optimism 主网、X Layer 和 opBNB）相比，Gate Layer 拥有更低的 Gas 费用和更高的区块 Gas 上限，这意味着当 Layer 2 的流量增加时，其 Gas 费用将更加稳定。

| | Gate Layer | opBNB | X Layer | Optimism |
| :--- | :--- | :--- | :--- | :--- |
| **Gas 代币** | GT | BNB | OKB | ETH |
| **虚拟机** | EVM | EVM | EVM | EVM |
| **Rollup 方案** | op rollup (op stack) | op rollup (op stack) | zk rollup (polygon CDK) | op rollup (op stack) |
| **Gas 价格 ($)** | 0.00000000002 | 0.000000000087 | 0.000000002074 | 0.000000003758 |
| **普通转账成本 ($)** | 0.0000003549 | 0.0000182952 | 0.0004355400 | 0.0007891800 |
| **区块 Gas 上限** | 120 M | 100 M | - | 30 M |
| **出块时间** | 1s | 1s | 0.47s | 2.13s |
| **最大 TPS** | 5,713 | 4,500 | 5,000 | 700 |
