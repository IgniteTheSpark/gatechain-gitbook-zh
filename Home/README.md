# Gate 区块链生态系统

Gate 集团构建了完整的区块链基础设施体系，通过 GateChain 主链和 GateLayer 扩容解决方案，为开发者和用户提供高性能、低成本、安全可靠的区块链服务。

---

### [GateChain](./GateChain/README.md)

高性能主链网络，支持智能合约、DeFi 生态和跨链互操作，为整个生态系统提供安全可靠的底层基础设施。

*   主链
*   智能合约
*   跨链

---

### [GateLayer](./GateLayer/README.md)

基于 GateChain 的 Layer 2 扩容解决方案，提供超高 TPS 和极低费用，完美适配 DeFi、游戏和 NFT 应用。

*   Layer 2
*   高性能
*   低费用
