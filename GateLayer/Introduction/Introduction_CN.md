# 什么是 Gate Layer

Gate Layer 是一个基于 Optimism OP Stack 构建的高性能 Layer 2 网络，完全兼容以太坊虚拟机 (EVM)。它利用 GateChain 作为其安全的结算层（由 GT 质押保障），并集成了原生的基于 Blob 的数据可用性，以提供可扩展、可靠且经济高效的基础设施。通过优化的参数，GateLayer 实现了超过 5,700 TPS 和极低的交易费用，在不牺牲安全性的前提下同时提供了速度和经济性。

GateLayer 旨在为多样化的去中心化应用提供支持——从 Meme 生态系统和永续合约交易所到游戏、DeFi 和社交平台。开发者可以受益于一个开放、无需许可的环境和熟悉的 EVM 工具链，而用户则能体验到无缝、低成本的交易。通过集成 LayerZero，GateLayer 还实现了跨多个区块链的原生互操作性，将其影响力扩展到单一生态系统之外，并为更广泛的跨链创新释放了更多可能性。
