# 官方桥

Gate Layer 官方桥允许您在 GateChain 和 Gate Layer 之间转移资产。这是将资金移入或移出 Layer 2 网络的主要且推荐的方式。

## 跨链桥 URL

| 网络 | URL | 状态 |
| :--- | :--- | :--- |
| Gate Layer 主网桥 | `待定` | 未上线 |
| Gate Layer 测试网桥 | `待定` | 未上线 |

对于希望集成跨链桥功能的开发者，请参考 [链上合约](./ProtocolContracts_CN.md) 文档，以获取 `L1StandardBridge` 及其他核心组件的地址。
