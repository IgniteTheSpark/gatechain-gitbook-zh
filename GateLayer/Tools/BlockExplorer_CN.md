# 区块浏览器

Gate Layer 使用 GateScan（Blockscout 的一个定制化分叉版本）作为其官方区块浏览器。您可以通过它浏览和搜索 Gate Layer 网络上的区块、交易、地址以及其他链上活动。

## 网络

您可以通过以下链接访问各个网络的 GateScan：

| 网络 | URL | 状态 |
| :--- | :--- | :--- |
| Gate Layer 主网 | `待定` | 未上线 |
| Gate Layer 测试网 | [https://gatescan.org/gatelayer-testnet](https://gatescan.org/gatelayer-testnet) | 已上线 |
